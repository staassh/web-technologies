Контрольні запитання — Лабораторна робота №2
Тема: Ознайомлення з мовою HTML. Семантична розмітка документів за стандартом HTML5.


1. Що таке HTML і яка його основна функція в веб-розробці?

HTML (HyperText Markup Language - мова гіпертекстової розмітки) - це не мова
програмування, а мова розмітки, за допомогою якої описується структура та вміст
веб-сторінки. Основна функція HTML — визначати, з яких елементів складається
сторінка (заголовки, абзаци, списки, зображення, посилання тощо) і в якому порядку
вони розташовані, щоб браузер міг правильно їх відобразити.


2. Яка структура HTML-документа?

Найпростіший HTML-документ має вигляд:

<!DOCTYPE html>
<html lang="en">
<head>
    <title></title>
</head>
<body>
...
</body>
</html>

- <!DOCTYPE html> - оголошення, що визначає документ як HTML5.
- <html> - кореневий елемент сторінки, всередині якого міститься весь код.
- <head> - містить метаінформацію про документ (заголовок сторінки, метатеги,
  підключення стилів і скриптів), яка сама по собі не відображається на сторінці
  (за винятком <title>).
- <body> - містить видимий вміст сторінки, який бачить користувач у браузері.


3. Чим парні теги відрізняються від непарних? Наведіть приклади.

Парні (контейнерні) теги складаються з відкриваючого і закриваючого тега та можуть
містити в собі текст або інші теги. Приклад: <p>Абзац тексту</p>, <h2><em>Заголовок</em></h2>.

Непарні (порожні, одиночні) теги не мають закриваючого тега і не можуть містити
вміст — вони самі є завершеним елементом. Приклад: <br>, <hr>,
<img src="photo.jpg" width="640" height="480" alt="Alt text for photo">.


4. Яке значення має тег <!DOCTYPE> в HTML-документі?

<!DOCTYPE html> - це не тег у звичайному розумінні, а спеціальна декларація, яка
розміщується на самому початку документа. Вона повідомляє браузеру, що документ
написаний за стандартом HTML5, і вказує, у якому режимі браузер має його
обробляти й відображати.


5. Що таке атрибути тегів і як вони використовуються?

Атрибути - це додаткові параметри тега, які задають його властивості або
поведінку. Записуються всередині відкриваючого тега у форматі ім'я="значення".
Наприклад, у тегу <img src="photo.jpg" width="640" height="480" alt="Alt text for photo">
атрибути src, width, height і alt визначають адресу зображення, його розміри та
альтернативний текст. Атрибути можуть бути обов'язковими (наприклад, src для
<img>) або необов'язковими.


6. Як створити заголовок різного рівня (наприклад, <h1>, <h2>) в HTML?

Для заголовків використовуються теги від <h1> (найвищий, найважливіший рівень)
до <h6> (найнижчий рівень), наприклад:

<h1>Заголовок 1 рівня</h1>
<h2>Заголовок 2 рівня</h2>

Ці теги не можуть бути вкладеними один в одного, але можуть містити теги
фізичного стилю тексту (<b>, <i> тощо). У них є атрибут align, який задає
вирівнювання заголовка (left, center, right, justify).


7. Які теги використовуються для створення списків (нумерованих та маркованих) в HTML?

- <ol> - створює нумерований список (елементи позначаються цифрами або буквами).
- <ul> - створює маркований список (елементи позначаються крапками/маркерами).
- <li> - використовується всередині <ol> або <ul> для позначення кожного окремого
  пункту списку.

Приклад:
<ol>
    <li>Перший пункт</li>
    <li>Другий пункт</li>
</ol>


8. Який тег використовується для створення посилання і як його правильно оформити?

Для створення гіперпосилань використовується контейнерний тег <a> з обов'язковим
атрибутом href, який вказує адресу переходу:

<a href="гіперпосилання">Текст посилання</a>

Додаткові атрибути:
- title - спливаюча підказка при наведенні курсору;
- target - вказує, де відкрити посилання (наприклад, target="_blank" відкриває
  в новій вкладці).

Щоб зробити картинку посиланням, тег <img> вставляють усередину <a>:

<a href="https://google.com.ua" title="https://google.com.ua" target="_blank">
    <img src="image/shark.jpg" alt="">
</a>


9. Як налаштувати інтегроване середовище розробки (IDE) для роботи з HTML-документами?

Для роботи з HTML найчастіше використовують редактор Visual Studio Code. Базове
налаштування включає:
1. Встановити VS Code з офіційного сайту code.visualstudio.com.
2. Встановити розширення "Live Server" (з магазину розширень усередині VS Code) -
   воно дозволяє відкривати HTML-сторінку в браузері з автооновленням при
   збереженні файлу.
3. Створити проєкт (папку) і всередині неї — файли з розширенням .html.
4. Для швидкого створення базової структури документа можна скористатися
   вбудованим шаблоном Emmet: ввести "!" і натиснути Tab — VS Code автоматично
   згенерує заготовку <!DOCTYPE html> з тегами html/head/body.
5. Для перегляду результату — клацнути правою кнопкою миші по html-файлу і
   обрати "Open with Live Server", або відкрити файл подвійним кліком у
   провіднику (тоді він відкриється в браузері за замовчуванням).


10. Що таке коментарі в HTML і як вони записуються?

Коментарі - це фрагменти тексту в коді, які браузер повністю ігнорує і не
відображає на сторінці. Вони використовуються для пояснень до коду, тимчасового
"вимкнення" частини розмітки або нотаток для розробника. Записуються між
спеціальними символами:

<!-- Текст коментаря -->

Коментар може займати один рядок або кілька рядків і не може бути вкладеним
(усередині одного коментаря не можна розмістити інший).
