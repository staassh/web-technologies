ЛАБОРАТОРНА РОБОТА №3
Тема: Основні теги HTML

ВІДПОВІДІ НА КОНТРОЛЬНІ ПИТАННЯ

1. Що таке HTML і яку роль він відіграє у створенні веб-сторінок?

HTML (HyperText Markup Language) — це мова розмітки, яка використовується для створення структури веб-сторінки. За допомогою HTML задають заголовки, абзаци, списки, таблиці, зображення, посилання, форми та інші елементи сторінки. HTML визначає структуру і вміст, а зовнішній вигляд зазвичай задається за допомогою CSS.

2. Яка структура базового HTML-документа? Назвіть обов’язкові елементи.

Базова структура HTML-документа:

<!doctype html>
<html lang="uk">
<head>
    <meta charset="UTF-8">
    <title>Назва сторінки</title>
</head>
<body>
    Вміст сторінки
</body>
</html>

Основні елементи:
- <!doctype html> — повідомляє браузеру, що використовується HTML5;
- <html> — кореневий елемент документа;
- <head> — службова інформація про сторінку;
- <meta> — метадані, наприклад кодування;
- <title> — назва вкладки браузера;
- <body> — видимий вміст сторінки.

3. Який тег використовується для створення гіперпосилання? Як відкрити його в новій вкладці?

Для створення гіперпосилання використовується тег <a>.

Приклад:
<a href="https://example.com">Перейти на сайт</a>

Щоб посилання відкривалося в новій вкладці, використовується атрибут target="_blank":

<a href="https://example.com" target="_blank">Перейти на сайт</a>

4. Які теги використовуються для створення заголовків? Скільки рівнів заголовків існує?

Для заголовків використовуються теги:
<h1>, <h2>, <h3>, <h4>, <h5>, <h6>.

У HTML існує 6 рівнів заголовків.
<h1> — найважливіший і найбільший заголовок,
<h6> — найменший за рівнем важливості.

5. Чим відрізняються теги <ul> і <ol>? Для чого вони використовуються?

<ul> створює маркований список.
<ol> створює нумерований список.

Елементи обох списків задаються тегом <li>.

Приклад маркованого списку:
<ul>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
</ul>

Приклад нумерованого списку:
<ol>
    <li>Пункт 1</li>
    <li>Пункт 2</li>
</ol>

6. Які атрибути використовуються для встановлення зображень і як задавати їх розміри?

Для вставлення зображення використовується тег <img>.

Основні атрибути:
- src — шлях до зображення;
- alt — альтернативний текст;
- width — ширина;
- height — висота.

Приклад:
<img src="img/photo.jpg" alt="Фотографія" width="400" height="400">

Розміри також можна задавати через CSS.

7. Як створити таблицю в HTML? Назвіть основні теги.

Основні теги таблиці:
- <table> — таблиця;
- <tr> — рядок;
- <td> — звичайна комірка;
- <th> — комірка-заголовок.

Додатково можуть використовуватися:
- <caption> — назва таблиці;
- <thead> — заголовкова частина;
- <tbody> — основна частина;
- <tfoot> — нижня частина.

Для об’єднання комірок:
- colspan — об’єднання по горизонталі;
- rowspan — об’єднання по вертикалі.

8. Який тег використовується для створення абзацу?

Для створення абзацу використовується тег <p>.

Приклад:
<p>Це звичайний абзац тексту.</p>

Браузер автоматично додає відступи між абзацами.

9. Як створити форму для введення даних користувачем? Назвіть основні теги та атрибути.

Форма створюється за допомогою тегу <form>.

Основні елементи форми:
- <input> — поле введення;
- <textarea> — багаторядкове текстове поле;
- <select> — список вибору;
- <option> — пункт списку;
- <button> — кнопка;
- <label> — підпис поля;
- <fieldset> — групування елементів;
- <legend> — заголовок групи.

Основні атрибути:
- action — адреса, куди відправляються дані;
- method — метод відправлення GET або POST;
- name — ім’я елемента;
- value — значення;
- type — тип поля;
- required — обов’язкове поле;
- placeholder — підказка;
- pattern — регулярний вираз для перевірки;
- checked — вибір за замовчуванням для radio/checkbox;
- selected — вибір за замовчуванням у списку;
- multiple — можливість вибору кількох значень.

10. Що таке семантична розмітка і чому вона важлива для доступності та SEO?

Семантична розмітка — це використання HTML-тегів відповідно до їхнього змістового призначення.

Приклади семантичних тегів:
- <header> — шапка сторінки;
- <nav> — навігація;
- <main> — основний вміст;
- <section> — розділ;
- <article> — окремий матеріал;
- <aside> — додаткова інформація;
- <footer> — нижня частина сторінки.

Семантична розмітка:
- робить структуру сторінки зрозумілішою;
- допомагає програмам екранного доступу;
- покращує доступність сайту;
- допомагає пошуковим системам краще розуміти вміст сторінки;
- позитивно впливає на SEO.
