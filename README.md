**Спеціальність:** Комп'ютерні науки (Технології штучного інтелекту)

Під час виконання лабораторної роботи я навчився/навчилась:
- створювати fork репозиторію та клонувати його
- працювати з гілками (`branch`), робити `commit` та `push`
- синхронізувати свою гілку з `upstream` через `merge`
- створювати Pull Request через веб-інтерфейс GitHub

*Враження:* спочатку робота з Git здавалась заплутаною через багато термінів (origin, upstream, branch), але після практики стало набагато зрозуміліше.
