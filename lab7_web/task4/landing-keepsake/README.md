# Keepsake — responsive landing page

Адаптивний односторінковий сайт за вимогами лабораторної №7 та наданим оглядом Figma Desktop, Tablet і Mobile. Реалізований на HTML5 та CSS без JS, фреймворків і UI-бібліотек.

## Рішення

- Mobile-first стилі з контрольними точками 768 px і 1280 px; максимальна ширина контенту 1100 px.
- Flexbox для навігації, кнопок, форми та автора відгуку; CSS Grid для портфоліо, послуг, статистики, клієнтів і журналу.
- Кольори, шрифти й ключові відступи зібрано в CSS-змінних у css/style.css.
- Мобільне меню відкривається нативним елементом details/summary без JavaScript. Фільтр портфоліо використовує :checked ~ і data-category.
- Зображення WebP з width/height і loading=lazy; SVG-іконки вставлено inline. Форма перевіряє email та згоду, але не надсилає дані.
- Є семантичні секції, один h1, alt-тексти та видимий клавіатурний фокус.

## Запуск і публікація

Відкрий index.html у браузері. За методичкою цю папку потрібно помістити в окремий репозиторій landing-keepsake та ввімкнути GitHub Pages для гілки main і кореня репозиторію. Після публікації додай сюди фактичне посилання на демо. Статус: очікує публікації у GitHub Pages — доступу до GitHub-акаунту в цьому завданні немає.
