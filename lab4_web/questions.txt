Контрольні запитання — Лабораторна робота №4

1. Яка CSS-властивість використовується для зміни типу шрифту елемента?
Відповідь: font-family. Вона задає сімейство шрифту, наприклад:
font-family: Arial, sans-serif;

2. Як за допомогою CSS змінити розмір шрифту?
Відповідь: за допомогою властивості font-size.
Приклад:
font-size: 20px;

3. Для чого використовується властивість font-weight?
Відповідь: для встановлення товщини (насиченості) шрифту.
Наприклад:
font-weight: bold;
або
font-weight: 700;

4. Яке значення властивості font-style задає курсивне написання тексту?
Відповідь: italic.
Приклад:
font-style: italic;

5. Як користатися скороченим записом властивості font? Наведи приклад.
Відповідь: властивість font дозволяє в одному рядку задати кілька параметрів шрифту.
Приклад:
font: italic bold 20px Arial, sans-serif;

6. Якою властивістю можна задати відстань між літерами у тексті?
Відповідь: letter-spacing.
Приклад:
letter-spacing: 5px;

7. Яка різниця між властивостями text-align та vertical-align?
Відповідь:
text-align задає горизонтальне вирівнювання тексту (left, center, right, justify).
vertical-align задає вертикальне вирівнювання елемента відносно сусідніх елементів або рядка.

8. Як за допомогою CSS зробити текст підкресленим або перекресленим?
Відповідь: за допомогою властивості text-decoration.
Підкреслення:
text-decoration: underline;
Перекреслення:
text-decoration: line-through;

9. Що робить властивість text-transform і які вона має основні значення?
Відповідь: змінює регістр символів у тексті.
Основні значення:
uppercase — усі літери великі;
lowercase — усі літери малі;
capitalize — перша літера кожного слова велика;
none — без змін.

10. Як можна задати міжрядковий інтервал у тексті?
Відповідь: за допомогою властивості line-height.
Приклад:
line-height: 40px;

11. Що робить властивість text-shadow і як виглядає її синтаксис?
Відповідь: додає тінь до тексту.
Синтаксис:
text-shadow: горизонтальне_зміщення вертикальне_зміщення розмиття колір;
Приклад:
text-shadow: 3px 3px 5px gray;

12. Як за допомогою селекторів застосувати стиль лише до певного елемента з конкретним класом?
Відповідь: записати тег і клас разом.
Наприклад:
p.text {
    color: red;
}
Цей стиль застосовується лише до тегів <p> з класом text.

13. У чому різниця між селекторами класу (.class) і ідентифікатора (#id)?
Відповідь:
.class використовується для одного або багатьох елементів і може повторюватися.
#id використовується для унікального елемента на сторінці.
Приклад:
.text { color: red; }
#title { color: blue; }

14. Як вибрати всі елементи <p>, які знаходяться всередині елемента з класом .content?
Відповідь:
.content p {
    color: red;
}
Це комбінатор нащадків: він вибирає всі <p> всередині елемента з класом content.

15. Який пріоритет мають різні типи селекторів у CSS (тег, клас, id, inline-стиль)?
Відповідь: від меншого пріоритету до більшого:
селектор тегу → селектор класу → селектор id → inline-стиль.

Тобто:
tag < .class < #id < style=""
