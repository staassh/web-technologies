# Лабораторна робота №4

**Тема:** CSS-властивості шрифту та тексту. Застосування селекторів.

У лабораторній роботі виконано 4 завдання з використанням CSS для форматування тексту, роботи зі списками та різними типами селекторів і комбінаторів.

## Виконано
- форматування тексту за допомогою CSS;
- використання селекторів тегів, класів та `id`;
- робота з багаторівневими списками;
- використання маркерів списків і зображень;
- застосування дочірніх, сусідніх та інших CSS-комбінаторів.

## Структура проєкту

```text
lab4_web/
├── index.html
├── task1/
│   ├── lab4_1.html
│   └── style.css
├── task2/
│   ├── lab4_2.html
│   └── style.css
├── task3/
│   ├── lab4_3.html
│   ├── style.css
│   └── img/
│       └── check.svg
└── task4/
    ├── lab4_4.html
    ├── style.css
    └── img/
        ├── image1.svg
        ├── image2.svg
        └── marker.svg
```

Для кожного завдання використовується окремий файл `style.css`.
