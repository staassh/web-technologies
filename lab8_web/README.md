# Лабораторна робота №8 — Основи CSS Grid Layout (Парний варіант)

## Структура репозиторію

- `task1/task1.jpg` — скріншот проходження інтерактивної гри **CSS Grid Garden** (28/28 рівнів).
- `task2/` — скріншот 100% прогресу курсу **CSS Grid** (`progress.png`) та повторений код усіх 25 відеоуроків у папках `01-welcome` — `25-full-bleed-blog-layout`.
- `task3/` — адаптивна фотогалерея на CSS Grid Layout для парного номера в списку (сітка 5×3 з великим центральним фото та медіазапитами для `768px` і `576px`).
- `task4/` — сітка карток на CSS Grid Layout для парного номера (ліва велика картка зі схемою треків Grid на 2 рядки + 5 карток праворуч із захистом від переповнення контенту та адаптацією під `768px` і `576px`).
- `task5/` — адаптивний Mobile-First макет сторінки (`header`, `navigation`, `main`, `sidebar`, `ads`, `footer`), реалізований двома способами:
  - `method1-lines/` — за допомогою координат ліній (`grid-column` та `grid-row`);
  - `method2-areas/` — за допомогою іменованих областей (`grid-template-areas` та `grid-area`).
- `task6/` — деревовидна структура з 28 блоків у 6 рядків (парний варіант) із нумерацією через CSS-лічильники (`counter-reset`, `counter-increment`, `::before`).
- `control-questions.md` — відповіді на всі 15 контрольних запитань.

## Дотримання вимог

- У всіх завданнях використано скидання стилів (`box-sizing: border-box; margin: 0; padding: 0;`) та CSS-змінні (`:root`).
- Верстка виконана на чистому HTML5 та CSS3 без сторонніх UI-бібліотек.
