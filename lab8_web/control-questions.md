# Контрольні запитання до Лабораторної роботи №8 (CSS Grid Layout)

### 1. Що таке CSS Grid Layout і для яких завдань веброзробки він використовується?
**CSS Grid Layout** — це двовимірна система компонування у CSS, яка дозволяє одночасно керувати розміщенням елементів по рядках і стовпцях. Використовується для побудови складних сіток сторінок (макромакетів), адаптивних фотогалерей, карток товарів, дашбордів і комбінованих інтерфейсів без зайвих обгорток у HTML.

### 2. У чому полягають основні відмінності між CSS Grid Layout та Flexbox?
* **Вимірність:** Flexbox — одновимірна модель (вирівнює елементи вздовж однієї осі: рядок *або* стовпець), тоді як CSS Grid — двовимірна (працює з рядками та стовпцями одночасно).
* **Підхід до побудови:** Flexbox працює від контенту (content-first — розміри елементів диктують вигляд рядка), а Grid — від макета (layout-first — спочатку задається жорстка або гнучка сітка, а потім у неї вкладається контент).

### 3. Як створити grid-контейнер? Чим відрізняються значення `grid` та `inline-grid` властивості `display`?
Grid-контейнер створюється заданням властивості `display: grid` або `display: inline-grid` батьківському елементу.
* `display: grid` робить контейнер **блочним** (він займає всю доступну ширину батька і починається з нового рядка).
* `display: inline-grid` робить контейнер **рядково-блочним** (його ширина підлаштовується під вміст, і він може стояти в один рядок з іншими інлайн-елементами).

### 4. Що таке grid-контейнер, grid-елемент, grid-лінія, grid-трек, grid-комірка та grid-область?
* **Grid-контейнер:** батьківський елемент із `display: grid`.
* **Grid-елемент (grid item):** прямий дочірній елемент grid-контейнера.
* **Grid-лінія (grid line):** роздільна вертикальна або горизонтальна лінія, що утворює структуру сітки (нумеруються з 1 або з -1 з кінця).
* **Grid-трек (grid track):** простір між двома сусідніми паралельними grid-лініями (тобто один рядок або один стовпець).
* **Grid-комірка (grid cell):** найменша одиниця сітки на перетині одного рядка та одного стовпця.
* **Grid-область (grid area):** прямокутна ділянка з однієї або кількох суміжних комірок, обмежена чотирма grid-лініями.

### 5. Для чого використовуються властивості `grid-template-columns` та `grid-template-rows`?
Вони визначають структуру явної сітки (explicit grid): задають кількість стовпців (`grid-template-columns`) і рядків (`grid-template-rows`), а також їхні розміри (у `px`, `%`, `fr`, `auto`, через `minmax()` тощо).

### 6. Що таке одиниця вимірювання `fr` і як вона використовується для розподілу доступного простору в CSS Grid?
`fr` (*fraction* — частка) — це гнучка одиниця, яка представляє частку **вільного** простору в grid-контейнері (після вирахування фіксованих розмірів і відступів `gap`). Наприклад, `1fr 2fr` поділить вільний простір на 3 частини: перший стовпець отримає 1/3, другий — 2/3.

### 7. Для чого призначені функції `repeat()`, `minmax()` та `fit-content()` у CSS Grid?
* `repeat(count, track)` — скорочує запис повторюваних треків (наприклад, `repeat(4, 1fr)`).
* `minmax(min, max)` — задає діапазон розмірів треку: не менше `min` і не більше `max` (наприклад, `minmax(250px, 1fr)`).
* `fit-content(limit)` — стискає трек за розміром контенту, але не дозволяє йому перевищити вказане граничне значення `limit`.

### 8. У чому полягає різниця між ключовими словами `auto-fill` та `auto-fit` під час використання функції `repeat()`?
Обидва ключові слова автоматично розміщують стільки колонок заданого розміру, скільки поміщається в контейнер. Різниця проявляється, коли елементів менше, ніж доступних колонок:
* `auto-fill` зберігає порожні створені треки (вони займають місце у сітці).
* `auto-fit` згортає (обнуляє) порожні треки до `0px` і розтягує наявні елементи на всю ширину контейнера.

### 9. Як працює властивість `gap` та чим відрізняються `row-gap` і `column-gap`?
`gap` задає проміжки (інтервали) виключно **між** сусідніми треками сітки (не додаючи відступів по зовнішніх краях контейнера).
* `row-gap` задає вертикальний відступ між рядками.
* `column-gap` задає горизонтальний відступ між стовпцями.
* Скорочений запис `gap: 20px 10px` встановлює `row-gap: 20px` і `column-gap: 10px`.

### 10. Для чого використовуються властивості `grid-column` та `grid-row`? Як за їх допомогою керувати розташуванням і розмірами grid-елементів?
Це скорочені властивості для `grid-column-start / grid-column-end` та `grid-row-start / grid-row-end`. Вони дозволяють вказати, з якої лінії починається і на якій закінчується елемент, або скільки треків він охоплює через ключове слово `span` (наприклад, `grid-column: 2 / 5` або `grid-row: span 2`).

### 11. Що таке іменовані grid-області та як використовувати властивості `grid-template-areas` і `grid-area`?
Іменовані області дозволяють візуально описати макет сітки у вигляді ASCII-схеми в контейнері через `grid-template-areas` (наприклад, `"header header" "sidebar main"`), а потім прив'язати кожен дочірній елемент до свого імені за допомогою властивості `grid-area: header`.

### 12. Як працюють властивості `justify-items`, `align-items`, `justify-content` та `align-content` у grid-контейнері?
* `justify-items` — вирівнює вміст усіх елементів **усередині їхніх комірок** по горизонталі (рядковій осі).
* `align-items` — вирівнює вміст усіх елементів **усередині їхніх комірок** по вертикалі (блочній осі).
* `justify-content` — вирівнює **всю сітку треків** усередині контейнера по горизонталі, якщо загальна ширина колонок менша за ширину контейнера.
* `align-content` — вирівнює **всю сітку треків** усередині контейнера по вертикалі, якщо загальна висота рядків менша за висоту контейнера.

### 13. У чому полягає різниця між явною (explicit grid) та неявною (implicit grid) сітками? Для чого призначені властивості `grid-auto-rows` і `grid-auto-columns`?
* **Явна сітка** складається з рядків і стовпців, чітко визначених у `grid-template-rows` та `grid-template-columns`.
* **Неявна сітка** створюється браузером автоматично, коли елементів більше, ніж комірок у явній сітці, або коли елемент розміщено за її межами.
* Властивості `grid-auto-rows` та `grid-auto-columns` задають розмір таким автоматично створеним рядкам і стовпцям.

### 14. Як працює властивість `grid-auto-flow` та як вона впливає на автоматичне розміщення елементів у сітці?
`grid-auto-flow` керує алгоритмом авторозміщення елементів, для яких не задані точні координати:
* `row` (за замовчуванням) — заповнює сітку по рядках зліва направо.
* `column` — заповнює сітку по стовпцях зверху вниз.
* `dense` (наприклад, `row dense`) — вмикає «щільне» пакування: браузер повертається назад і заповнює порожні «дірки» в сітці меншими елементами, які йдуть далі в HTML.

### 15. Як створити адаптивний макет за допомогою CSS Grid із використанням `repeat()`, `minmax()`, `auto-fit` та медіазапитів?
1. **Без медіазапитів (автоматична адаптація карток):** задається `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));` — колонки самі переносяться на новий рядок, коли стають вужчими за `260px`, і рівномірно розтягуються на вільну ширину.
2. **Із медіазапитами (Mobile-First):** спочатку задається одноколонкова сітка (`grid-template-columns: 1fr`), а на контрольних точках `@media (min-width: 768px)` та `@media (min-width: 1024px)` змінюються `grid-template-columns`, `grid-template-areas` або `grid-column / grid-row`.
