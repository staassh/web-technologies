# Лабораторна робота №5

CSS-властивості блоків та фону. Для перегляду розпакуйте архів і відкрийте `index.html`.

Кожне з шести завдань знаходиться у власній папці та підключає зовнішній `style.css`.
Назви файлів — `lab5_1.html`–`lab5_6.html`, папки й архіву — `lab5_web`, відповідно до вимоги користувача.

Завдання 3 використовує наданий `questionnaire.html` з лабораторної №3: поля, структура,
підписи, списки й правила валідації збережені, додано зовнішнє CSS-оформлення.
GET і POST демонструють налаштування HTML-форм; серверне збереження даних не реалізоване,
оскільки методичка вимагає оформлення анкети, а не серверний обробник.

Завдання 1 відтворює надану користувачем схему та візуальний зразок.
Ширина контейнера 500px включає padding; висота 559px. Палітра взята зі скріншота.
У `task1/icons/reference.png` знаходиться зразок, використаний як CSS-спрайт
виключно для піктограм. Усі тексти, вкладені списки й кольорові блоки — HTML/CSS.
На скріншоті приклад збільшений приблизно в 1,536 раза; пропорції збережені. Зображення завдання 6 знаходяться в `task6/img`.
Завдання 4 використовує лише CSS-градієнти, без файлів зображень.

У завданні 4 фактичний проміжок між сусідніми блоками в рядку дорівнює 20px.
У завданні 5 overflow розміщений після меню: visible виходить за рамку, але не перекриває меню.
Розміри демонстраційних блоків, задані методичкою, не зменшуються на мобільному екрані.
Для contain/cover у завданні 6 за потреби прокручується локальна область.

Відповіді на контрольні запитання — `questions_answers.md`.
Для здачі додайте цю папку до особистого репозиторію `web-technologies`.
